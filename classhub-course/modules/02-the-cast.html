The Cast — Who Does What in the Codebase

Every codebase has characters with specific jobs. Know them and you'll always know which file to tell AI to change.

The map of the codebase

ClassHub's source code lives entirely inside src/. It's split into clean folders — each with a specific job. Think of it like a theatre backstage: different areas handle costumes, lighting, scripts, and stage mechanics.

src/
App.tsx — The director: sets up routing and auth wrappers
main.tsx — The stage door: mounts React into index.html
pages/ — Full-screen views, one per route
SignIn.tsx — The login screen
app/ — All authenticated pages
DashboardPage.tsx
AnnouncementsPage.tsx
PollsPage.tsx
AttendancePage.tsx — and 10 more…
onboarding/ — Join/create a section hub
components/ — Reusable UI building blocks
AuthProvider.tsx — Manages the Google sign-in lifecycle
NavBar.tsx, Toast.tsx, BottomSheet.tsx…
hooks/ — Data-fetching logic, one hook per feature
useAttendance.ts, usePolls.ts, useAnnouncements.ts…
lib/ — Utilities and service clients
supabase.ts — The Supabase client singleton
realtimeBroker.ts — WebSocket subscription manager
offlineSync.ts — Replays actions after reconnecting
store/ — Global app-wide memory (Zustand)
appStore.ts — Session, user profile, offline cache

The golden rule for directing AI

When you say "change how attendance data looks," AI edits a Page. When you say "change what attendance data is fetched," AI edits a Hook. When you say "add a new database column," AI edits a Supabase migration. Knowing the layer prevents AI from editing the wrong file.

How a page asks a hook for data

Here's a simplified version of how AttendancePage.tsx gets data. This single-import pattern is how all pages in ClassHub work — the page owns the layout, the hook owns the data.

TypeScript — AttendancePage.tsx import { useAttendance } from '../hooks/useAttendance'   export default function AttendancePage() { const { data, isLoading, error } = useAttendance()   if (isLoading) return <LoadingSkeleton /> if (error) return <ErrorMessage />   return <AttendanceChart subjects={data.subjects} /> }
Plain English
Import the attendance hook from the hooks folder.
Call the hook inside the component — it handles all the fetching behind the scenes.
The hook returns three things: the data itself, a loading flag, and any error.
While loading: show a skeleton placeholder so the screen isn't blank.
If something went wrong: show an error message instead of crashing.
If data arrived: render the chart with the subjects array.
