ClassHub image attachments render inline previews through `src/components/AttachmentCard.tsx` using Supabase Storage signed URLs. To prevent reflow lag inside slide-up drawers, dynamic height animations are removed: the container maintains a stable 200px height while loading and seamlessly switches to `auto` height (conforming to the image aspect ratio up to 380px max-height) with a GPU-composited opacity fade-in once loaded.
