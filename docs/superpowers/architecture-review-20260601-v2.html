The Friction

AnnouncementQA.tsx is a monolithic file holding **1,015 lines of code**. It violates single-responsibility and component locality by forcing three distinct, complex sub-modules (reactions picker, comments editor thread, and the parent slidesheet drawer) to reside in the exact same workspace area, hindering testability and maintainability.

The Proposal

Decompose the monolith into a modular folder structure under src/components/announcement-qa/. Each visual sub-module will occupy a single, highly readable file (200-300 lines) with a focused external seam and clean TypeScript type definitions.

Architectural Wins

  • ✔ Locality: Layout structures and private hooks concentrate in distinct sub-modules.
  • ✔ Depth: Simplifies parent interfaces by hiding sub-module rendering details.
  • ✔ Deletes 1,000+ line monolith in favor of modular components.
  • ✔ Testability: Individual components can be isolated and unit-tested.

The Friction

The current real-time listener hook useAnnouncementQARealtime is called independently inside multiple child components. This spawns redundant, duplicate socket connections for the exact same announcement ID, violating connection efficiency and leaking websocket details.

The Proposal

Delegate Q&A real-time setups to our deep RealtimeBroker. Expose a single unified subscription method subscribeToAnnouncementQA and have the parent slidesheet mount a single connection, invalidating React Query states globally on database changes.

Architectural Wins

  • ✔ Locality: Web socket connection lifecycles remain entirely in the RealtimeBroker.
  • ✔ Socket Efficiency: Eliminates redundant, multi-socket duplicate calls.
  • ✔ Leverage: One channel invalidates multiple disjoint query keys automatically.

🎯 Top Recommendation: Split Monolithic AnnouncementQA UI Component

Decomposing the massive 1,000+ line AnnouncementQA monolith into a clean, localized component folder is our top priority. Storing reactions, comment threads, and triggers in individual, well-named files improves AI navigability, restores strict **locality** of layout edits, and simplifies testing immensely.
